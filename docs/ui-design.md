# 画面設計

> **最終更新:** 2026-11-03 · **対象:** Adobe Bridge 2026 · **方針:** レイアウト・パネル構成・操作は **Bridge を可能な限りそのまま再現する**。

この文書は記憶と公開資料に基づく初版です。各項目の `要観察` は、実装前に Bridge 2026 の実機で確認し、
観察結果（寸法・順序・文言・挙動）でこの文書を更新してください。手順は `.claude/skills/parity-observation/SKILL.md`。
Bridge のスクリーンショットはリポジトリにコミットせず、`plan/bridge/`（gitignore）に置きます。

## 0. 再現の原則

1. **位置を変えない。** ボタン・メニュー項目・パネルの順序と位置は Bridge と同じにする。「より良い配置」を思いついても、
   既定ワークスペースでは採用しない（カスタムワークスペースで実現できるようにする）。
2. **文言は Bridge の日本語版／英語版に合わせる**（ただし商標・製品名は Craft App 名に置換：「Photoshop」→「PhotoCraft」、
   「Camera Raw で開く」→「Camera Raw で開く（LightCraft）」等。詳細は [craft-integration.md](craft-integration.md)）。
3. **見た目はトークンで合わせる。** 色・余白・角丸・フォントサイズは `theme::Tokens` に定義し、Bridge の観察値を入れる。
   ハードコード禁止（photocraft の `docs/ui-design.md` と同じ方式）。
4. **アイコンは自作または寛容ライセンス。** Adobe のアイコンを複製しない。形の意味（矢印、星、ゴミ箱）は同じにしつつ、
   描画は独自 SVG（craft-ui の SVG カタログに合わせる）。
5. **ショートカットは完全一致。** [command-catalog.md](command-catalog.md) の表が正。

## 3. パスバー

- **左：パンくず。** 各セグメントをクリックで移動。セグメント後の `▸` をクリックでサブフォルダーのメニュー。
  空白部分をクリックするとテキスト入力になりパスを直接入力できる（要観察：Bridge は入力に対応しているか。非対応なら Cmd/Ctrl+Shift+G 等の別手段で提供）。
- **右（順に、要観察）：**
  1. ▣▾ サムネイルの品質とプレビュー生成のオプション：埋め込みを優先（高速）／必要に応じて高品質／常に高品質／100% プレビューを生成
  2. ★▾ レーティングでフィルター：すべての項目を表示／レーティングなしのみ／★以上〜★★★★★のみ／ラベル付きのみ／ラベルなしのみ／各ラベル／却下のみ
  3. 並べ替え ▾：ファイル名、ファイルの種類、作成日、変更日、撮影日、ファイルサイズ、寸法、解像度、カラープロファイル、レーティング、ラベル、キーワード、手動
  4. ↑↓ 昇順／降順の切り替え
  5. 📁+ 新規フォルダーを作成
  6. 🗑 項目を削除（ゴミ箱へ）

## 4. パネル

### 4.1 お気に入り

- 既定項目（環境設定 › 一般 › お気に入り項目でオン／オフ）：コンピューター、ホーム、デスクトップ、書類、ピクチャ（要観察：Bridge 2026 の既定項目）。
- 下部（区切り線の下）にユーザーが追加したフォルダー・ファイル。ドラッグで追加・並べ替え、右クリック › お気に入りから削除。
- コレクションもドラッグで追加できる（要観察）。

### 4.2 フォルダー

- ツリー。展開三角、遅延読み込み。選択でコンテンツを切り替え。
- 右クリック：新規フォルダー、名前の変更、お気に入りに追加、Finder で表示、ゴミ箱に入れる、キャッシュ（構築・パージ）、ロック（要観察）。
- コンテンツからフォルダーへのドロップで移動（Alt/Opt でコピー）。

### 4.3 コンテンツ

**サムネイル表示（既定）**

```text
┌────────────────┐
│▣3          ◎ ✂│  ← 左上：スタック件数バッジ、右上：現像設定あり・切り抜きありバッジ
│                │
│   (サムネイル)    │
│                │
│        ▶ 0:12  │  ← 動画：長さ表示、ホバーでスクラブ（CNT-13）
└────────────────┘

 ▔▔▔▔▔▔▔▔ (ラベル色の帯)   ← ラベル色はファイル名の背後の帯（要観察：Bridge 2026 の描画位置）

```

- 選択はサムネイル枠の背景色で示す（要観察：選択色とフォーカス枠の色）。
- サムネイル間の余白、名前行の高さはサムネイルサイズスライダーに連動。スライダーの最小・最大値は要観察。
- 却下（-1）はレーティング行に赤い「却下」表示。
- 読み取り専用／メタデータ書き込み不可のバッジ（Pier 独自。Bridge にない場合は右上の小アイコンで控えめに）。

**詳細表示**：左にサムネイル、右に 2 列でメタデータ（ファイル名、作成日、変更日、サイズ、種類、寸法…）。要観察：列内容。

**リスト表示**：列ヘッダー（名前、作成日、変更日、サイズ、種類、レーティング、ラベル…）。ヘッダー右クリックで列の追加・削除。列ドラッグで並べ替え。

**コンテキストメニュー（アセット）**：開く、指定アプリで開く ▸、Camera Raw で開く、最近使用したファイルを開く ▸、
カット、コピー、ペースト、複製、移動 ▸、コピー ▸、ゴミ箱に入れる、Finder で表示、お気に入りに追加、
スタック ▸、ラベル ▸、レーティング ▸、回転 ▸、メタデータテンプレート ▸、ファイル情報、キーワード ▸、
キャッシュ ▸、コレクションに追加 ▸、ツール ▸（PhotoCraft で処理…）。項目順は要観察。

### 4.4 プレビュー

- 1 枚選択：フィット表示。2〜9 枚：グリッド表示で比較（各画像の下にファイル名）。
- クリックでルーペ（100%）。ルーペはドラッグで移動、ホイール（または +/-）で 100〜800%、もう一度クリックで閉じる。
  Cmd/Ctrl+クリックで全画像にルーペを同期表示。
- 動画・音声：下部にコントロール（再生／一時停止、シーク、ループ、音量）。環境設定 › 再生で自動再生・ループ。
- マルチページ：下部にページ送り。

### 4.7 フィルター

- 現在の表示（フォルダー／コレクション／検索結果）から集計したカテゴリを縦に並べる。各値の右に件数。
- カテゴリ見出しは開閉。表示カテゴリはパネルメニューで選択。
- 下部：📌 参照中のフィルターを保持、⊘ フィルターをクリア。
- 値がない（件数 0）カテゴリは表示しない（要観察）。

### 4.8 コレクション

- コレクションとスマートコレクション（アイコンで区別）を一覧。件数表示。
- 下部：新規スマートコレクション、スマートコレクションを編集、新規コレクション、削除（要観察：ボタン順）。
- コレクション表示中は、コンテンツ上部に「コレクションから除去」などの帯を出す（要観察）。

### 4.9 書き出し

- プリセット一覧（既定：「ハードディスクに保存」JPEG）。サムネイルをプリセットへドラッグで書き出し開始。
- 「+ 新規プリセットを追加」でダイアログ（保存先、画像形式、画質、サイズ、メタデータ、キーワード）。
- 進捗は「書き出しの進捗状況」ウィンドウ（要観察）。

### 4.10 出力（出力ワークスペース専用）

- 上部：テンプレート ▾、［更新］、［PDF に書き出し］。
- セクション：ドキュメント（用紙サイズ、幅、高さ、品質、背景）、レイアウト（列、行、上下左右の余白、間隔、最適に回転）、
  オーバーレイ（ファイル名、拡張子、フォント、サイズ、色）、ヘッダー、フッター、透かし。
- 「出力プレビュー」パネルにページのプレビュー。

### 6.1 環境設定

出典：Bridge ヘルプ「Set workflow preferences」の macOS スクリーンショット（Bridge 2026 時点のアーカイブ）。実機未確認。

- 開き方：Adobe Bridge › 環境設定（⌘K。ショートカットはフォーラムの記述のみで要観察）。
- 左：枠付きの一覧、左揃え。順序は「一般」「詳細設定」のあと英語名の A–Z：
  General、Advanced、Applications、Cache、Cache Management、Content、Export、File Type Associations、Interface、Keywords、
  Labels and Ratings、Media Cache、Metadata、Output、Playback、Quick Actions、Startup Scripts、Thumbnails、Workflow。
- 日本語名：ヘルプで確認できたのは「詳細設定」「インターフェイス」「ワークフロー」だけ。ほか（一般、アプリケーション、キャッシュ、
  キャッシュ管理、コンテンツ、書き出し、ファイルの種類の関連付け、キーワード、ラベルとレーティング、メディアキャッシュ、メタデータ、
  出力、再生、クイックアクション、スタートアップスクリプト、サムネイル）は要観察。
- 右：選んだページの設定。ページを切り替えてもウィンドウの大きさは変わらない（Pier の実装。Bridge は要観察）。
- 下：右寄せで［キャンセル］［OK］。OK は青い既定ボタン。OK で確定、キャンセル・Esc で破棄（手順が「OK を選択」で終わることからの推定）。
  Windows 版のスクリーンショットは［OK］［キャンセル］の順で、一覧に Applications と Quick Actions がない（古い版か OS 差、要観察）。
- Return は OK、Esc はキャンセル（Pier の実装。macOS の既定ボタンの慣習に合わせた）。
- 要観察：リサイズの可否、寸法（pt）、ウィンドウ外クリックの扱い（Pier は今キャンセル扱い。egui のモーダルの既定で、Bridge と違う可能性がある）、前回のページを覚えるか。

## 8. テーマとトークン

| トークン | 用途 | 値 |
|---|---|---|
| `bg.app` | ウィンドウ背景 | 要計測（4 段階の明るさごと） |
| `bg.panel` / `bg.panelHeader` / `bg.tabActive` / `bg.tabInactive` | パネル | 要計測 |
| `bg.content` | コンテンツパネル背景（環境設定 › インターフェイス › 背景で変更可） | 要計測 |
| `fg.text` / `fg.textDim` / `fg.textDisabled` | 文字 | 要計測 |
| `accent.selection` / `accent.focus` | 選択・フォーカス | 要計測 |
| `label.select` / `label.second` / `label.approved` / `label.review` / `label.todo` | ラベル色 | 赤・黄・緑・青・紫（色値は要計測） |
| `star.on` / `star.off` | ★ | 要計測 |
| `size.font.ui` | UI 文字サイズ（小・中・大） | 要計測 |
| `space.*` / `radius.*` | 余白・角丸 | 要計測 |

- 明るさ 4 段階（最も暗い、暗い、明るい、最も明るい）を `pro` 系のテーマ名で用意する（photocraft の `pro` / `proMedium` / `studio` / `studioLight` と命名をそろえる）。
- フォント：UI は craft-fonts の UI フェイス（CJK はシステムフォント。craft-launcher と同じ探索順）。
- 計測方法：Bridge のスクリーンショットからピクセル値を測る（色・寸法は事実情報であり、コードや素材の複製ではない）。結果はこの表に書く。
