# 要件定義

> **最終更新:** 2026-11-03（最初の試作で `部分` を反映） · **対象:** Adobe Bridge 2026 · 状態列: `未` 未着手 / `部分` 一部実装 / `済` パリティ達成 / `—` 対象外

優先度:
- **P0** — 最初のリリース（M3）に必須。これが無いとアセットブラウザとして成立しない。
- **P1** — Bridge ユーザーが日常的に使う機能。ベータ（M6）までに。
- **P2** — ロングテール。1.0 までに。

Bridge の挙動が不明確な項目は「要観察」と書きます。実装前に Bridge 2026 で挙動を観察し、結果をこの表の備考に書き足してください。

## 2. 非機能要件

### 2.1 性能（NFR-P）

基準機：Apple M1 / 16GB、Core i5 第 10 世代 / 16GB + SSD。基準データ：24MP JPEG 1 万枚、raw（CR3/NEF/ARW）1 千枚、PSD 500 枚のフォルダ。

| ID | 項目 | 予算 |
|---|---|---|
| NFR-P1 | アプリ起動からウィンドウ表示 | 800ms 以内（コールド 1.5s） |
| NFR-P2 | 1 万ファイルのフォルダを開いてから一覧（ファイル名＋プレースホルダー）表示 | 300ms 以内 |
| NFR-P3 | キャッシュ済みフォルダのサムネイルが表示領域分そろう | 200ms 以内 |
| NFR-P4 | 未キャッシュ JPEG のサムネイル（埋め込みサムネイル使用） | 1 枚 5ms 以内（8 スレッドで 1 万枚 10s 以内） |
| NFR-P5 | スクロール | 60fps を維持（フレーム 16ms、UI スレッドでデコードしない） |
| NFR-P6 | フィルター・並べ替えの適用（1 万件） | 50ms 以内 |
| NFR-P7 | プレビュー表示（キャッシュ済み） | 100ms 以内。未キャッシュ 24MP JPEG は 400ms 以内 |
| NFR-P8 | メモリ使用量（1 万件表示中） | 1.5GB 以下。サムネイルの GPU テクスチャは表示範囲＋前後 2 画面分に制限 |
| NFR-P9 | メタデータ一括書き込み（JPEG 1 千枚に★） | 10s 以内 |

### 2.2 信頼性（NFR-R）

| ID | 要件 |
|---|---|
| NFR-R1 | 破損・悪意あるファイル（ファザーで生成）を投入しても panic しない。デコードはタイムアウト（既定 10s）とメモリ上限付き |
| NFR-R2 | すべてのファイル書き込みはアトミック。書き込み中の電源断・強制終了で元ファイルが失われない |
| NFR-R3 | キャッシュ DB が破損していたら、退避して再作成する（ユーザーデータ＝コレクション・キーワード辞書・手動並び順は別ファイルにバックアップ） |
| NFR-R4 | ネットワークボリュームの切断で UI が固まらない（ファイル I/O はすべてワーカー、タイムアウト付き） |
| NFR-R5 | クラッシュ時はクラッシュレポートをローカルに保存し、次回起動時に提示（送信はユーザー操作でのみ） |

### 2.3 セキュリティ・プライバシー（NFR-S）

| ID | 要件 |
|---|---|
| NFR-S1 | 既定でネットワーク通信をしない。更新確認（`craft-update`）・地図タイルはオプトイン |
| NFR-S2 | コントロールチャネルは loopback のみ、256bit トークン必須（photocraft と同方式） |
| NFR-S3 | MCP / CLI でのファイル操作は指定された読み取り／書き込みルート配下に限定 |
| NFR-S4 | Craft App 起動時は引数をシェルを介さずに渡す（コマンドインジェクション防止） |
| NFR-S5 | ドキュメント内パス（コレクション・スタック・スマートコレクション）を開くときは `craft-docpath` で検証 |

### 2.4 国際化・アクセシビリティ（NFR-I）

| ID | 要件 |
|---|---|
| NFR-I1 | UI 文字列は `craft-i18n` 経由。初期言語は英語・日本語。Craft Apps と同じ言語集合に順次対応 |
| NFR-I2 | ファイル名・メタデータの Unicode 正規化（macOS の NFD）を正しく扱い、検索は正規化後に比較 |
| NFR-I3 | キーボードだけで全機能を操作できる。フォーカス表示を明確にする |
| NFR-I4 | AccessKit（egui 経由）でスクリーンリーダーに主要要素を公開 |

### 2.5 プラットフォーム（NFR-X）

| ID | 要件 |
|---|---|
| NFR-X1 | macOS（Universal）、Windows（x64 / arm64）、Linux（x64 / arm64、X11 / Wayland）で同一機能 |
| NFR-X2 | 配布形式は Craft Apps と同じ（DMG、MSI、AppImage、.deb、.rpm、Flatpak）。ArtCraft Launcher のカタログ形式に載せられる命名にする |
| NFR-X3 | OS のゴミ箱、ファイル関連付け、ドラッグ＆ドロップ、Finder / エクスプローラーでの表示をネイティブに扱う |
| NFR-X4 | 単一インスタンス：2 回目の起動はパスを既存ウィンドウへ渡す（photocraft の `single_instance` と同方式） |
